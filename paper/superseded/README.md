# Superseded framings, kept on purpose

Two earlier main-line documents. Neither is current; both are here because the
project rule is that records are not deleted, and because the sequence of
reframings is itself part of what happened.

| file | what it argued | why it was replaced |
|---|---|---|
| `NARRATIVE.md` | the `(S, D, ω)` intrinsic state space, then the gauge frame as a free coordinate with a prescription | the prescription proved fragile (8B needed a 4x probe; Lion prefers a different frame), so leading with it forced a retreat every time an experiment failed |
| `STORY.md` | the same result reframed as "initialisation comparisons are optimizer-specific" | a critique, whose value is defined by someone else's error, and therefore defensive by construction |

The current main line is `../OUTLINE.md`, which states a constructive claim —
a map from optimizer to the part of the reparameterisation group it can see —
that does not narrow when a downstream experiment fails.
